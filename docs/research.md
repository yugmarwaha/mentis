# Research

These papers inform design hypotheses. They do not show that Mentis improves learning.

| Paper | Link | Conclusion |
|---|---|---|
| Generative AI Can Harm Learning (2025) | [PMC12232635](https://pmc.ncbi.nlm.nih.gov/articles/PMC12232635/) | AI help can raise practice scores but not later independent scores. |
| Roediger & Karpicke, Test-Enhanced Learning (2006) | [doi](https://doi.org/10.1111/j.1467-9280.2006.01693.x) | Retrieval from memory improves long-term retention more than repeated study. |
| Kapur, Productive Failure (2014) | [doi](https://doi.org/10.1111/cogs.12107) | Attempting a problem before instruction prepares students to learn from it. |
