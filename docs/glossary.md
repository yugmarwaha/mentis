# Glossary (draft)

Status: draft, not reviewed. Domain: introductory Python.

## Meaningful attempt
A learner message that shows the learner's own reasoning: how or why. The tutor can respond to that reasoning.

- Wrong attempts count.
- Length does not count.
- A bare guess does not count. Example: "maybe a loop?"
- In the assessment form, `partial` and `full` are meaningful. `none` and `guess` are not.

## Premature disclosure
A tutor message that gives the learner the answer, or enough that the remaining work is only copying, when the policy did not allow a solution.

- Disclosure: working code for the whole task. Disclosure: the key step, such as "Start `total` at 0 and add each item in a loop."
- Not disclosure: name a concept or ask a question, such as "What do you need to remember between steps?"

## Good intervention
A good intervention has two parts. Check both.

**Message quality.** The message meets all five:
1. It matches the action the policy chose.
2. It refers to something specific in this learner's message.
3. It has no premature disclosure.
4. What it says about the code is correct.
5. It leaves the next step to the learner. A question that leads to one obvious answer fails.

**Action quality.** The action the policy chose fits this learner at this point. Judge it against labeled examples.

Scope: these are checks on tutor behavior. They do not show that the learner learned.
