# Visuals

- Use a visual when it explains better than text: flows, states, data, comparisons.
- For a quick explanation, show the visual in the chat.
- For a diagram that must stay, write a Mermaid block in the Markdown file.
- For a large or interactive visual, write a temporary HTML page in the scratchpad folder. Never write it in the repository.
- Delete each temporary page after the developer reads it.
- Do not commit temporary visuals.
- Add a short caption in plain text. Follow `.claude/rules/writing-style.md`.
